## Art, audio and resource bounds

The three generated originals on disk match their Pass 08 hashes. The runtime uses derived painted cover sizes, catalog icons and Trial scene crops. These 1.9 images are static. The fixtures also observed 17 chapter raster draw calls and inherited fusion draws. PNG header, hash and fixture draw checks establish asset availability and integration. Animated presentation at phone scale still needs browser review. [Original manifest](IMAGE_MANIFEST.json) · [Derived art and six WAV cues](POLISH_MEDIA.json) · [Source hashes](pass10-source.sha256)

The 66 WAVs total 27,443,646 file bytes. Decoding all of them at once to 48 kHz float32 would take about 74.5 MiB before overhead. A single 24-second stereo district loop is about 8.8 MiB under that assumption. The active code keeps one cached district loop and the chapter code evicts prior chapter loops on chapter changes. City effects check a shared limit of eight active voices and the Trial caps live enemies at 12. These are file calculations and source bounds. Actual decode peaks and retained browser memory remain open.
