WHAT IS REAL

Development log

Playable core

Original canvas-based survival game with touch controls, automatic combat, pickups, health, difficulty scaling, sound, pause, local best score and replay. Real code, no AI video generation required.

Automation

GitHub Actions runs Python tests and deterministic agent-council balance experiments. Votes select a proposed configuration for review, not a public release. Actual edit of game rules is subject to approval.

What agents cannot yet do

The autonomous Council now runs scheduled model calls and records its decisions. Gameplay and mobile compatibility still require independent verification.

Recording content

The game can be played in the browser on your phone. Capture your own screen, voice and optional camera footage, then put the resulting package into BoRHeZ Games Studio.
