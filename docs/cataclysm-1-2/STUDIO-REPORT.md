## Shipped behavior

- New runs start at Night 1, Level 1, 3 HP and **exactly nine lives**. Normal damage/healing uses HP. Each lethal HP event consumes one life once. Eight returns are possible before the ninth death ends the run, unless the rare recovery succeeds.
- Death visibly freezes the world for **0.9 seconds**, shows an afterlife postal notice and cat banter, and plays a falling cue. Automatic return restores **60% maximum HP** and **2.8 seconds** of movement-enabled protection with a visible glow/countdown and rising cue. Pausing/backgrounding also freezes the transition and grace. Last life changes the HUD and banter.
- Revive retains the same XP, level, perks, fish, companions/ranks, pickups, kills, wave/night and encounter ledgers. No enemies are killed or rewards duplicated by revival. Only hostile projectiles within 110 world pixels are removed. Restart resets the run, card unlocks, reward eligibility and nine lives.
- Phone HUD has a numeric `LIVES n / 9`, nine pips, loss animation, last-life border/text and a separate live announcement. HP cards explicitly say they do not add lives. Reduced-motion mode removes the loss animation.
- Rare recovery: **one 18% lottery at 180 active seconds**, automatically claimed and announced, maximum **nine current lives**. At the cap it gives **+0.5 maximum HP and 0.5 healing** instead. Checked/claimed flags survive revival; no enemy, boss, pickup or repeated timer can farm it. Rule is disclosed in the pause guide. This is a timed windfall rather than a new exploration system.
- Three unique random upgrade offers initially; **Curiosity pays rent** unlocks four and grants one reroll; **Five brain cells**, eligible only afterward, unlocks five and grants one reroll. Two starting tokens; existing earned drops remain. Rerolls spend exactly one token and change at least one card identity, not just ordering. Repeatable core cards prevent empty pools. All cards remain frozen decisions; the fifth card scrolls on narrow screens.
- Twelve new perks: Curiosity, Five brain cells, Loaded yarn dice (+3 rerolls, twice); Emergency cardboard box (80% return HP, +1s grace); Purr therapy (0.06 HP/s after 8s unharmed, doubled solo); Bubble appointment (1.1s protection every 18 active seconds); Porcelain menace (+40% tail damage, ×0.75 max/current HP, twice); Return to zoom (+10% speed, +0.4s grace); Table for one (+30% tail damage and 15% mitigation only while alone); Group purr insurance (+0.025 HP/s per ally after 8s unharmed); Last laugh (+60% tail damage on last life); Haunted tail (+2 piercing for eight active seconds after return). All other new perks are single purchases.
- Preserved approved illustrated cat textures, enemies, seven ranged companion roles, melee Brawler, four unique slots, wave/boss systems, auto skills, music and voice system. Found and repaired a copied-baseline gap: the illustrated body bypassed the old renderer's gun. The existing drawn tail/pistol is now rendered over that body, with world-space aim and a shared muzzle formula for either body facing. No new weapons, companions, evolutions, map or fishing.

## Reproduce and test

1. Serve the repository with any static server, open `/docs/cataclysm-1-2/`, press Play and drag or use WASD. Shooting is automatic. Lose HP normally by standing in enemy contact; watch lives decrease separately from HP and the safe return timer. Repeat through zero; Play Again starts at nine.
2. Level up by collecting XP/fish. Choose Curiosity, then Five brain cells when randomly offered. Spend reroll tokens and compare card identities. Add Loaded yarn dice for more tokens. Escape during a decision leaves the decision frozen.
3. For quick deterministic reproduction, open `?qa=nine-lives&seed=123`, then in DevTools use `CATA_12_QA.lethal()` while running; it refuses another hit during transition/grace. `CATA_12_QA.offer()` opens cards; `CATA_12_QA.choose('curiosity')` selects an eligible fixture card, followed by another offer and `choose('omniscience')`. `CATA_12_QA.reward()` tests the one-shot reward including its cap. These mutation helpers exist **only** under the explicit QA query. Normal play uses the real lottery.
4. Run `node docs/cataclysm-1-2/qa/runtime.cjs`. It executes all shipped modules with local PNG/manifest loading against a DOM/canvas double. It checks full startup, render calls, movement, actual enemy-projectile HP/death, nine deaths, frozen transition/decision clocks, grace, retained progress, game over/restart, caps, repeat reward prevention, 3/4/5 offers, reroll exhaustion, companion eligibility, perk effect math, timed shield/piercing expiry and tail muzzle agreement. Result: **PASS**, see [runtime-results.json](./qa/runtime-results.json). This does not certify browser rendering.
5. Chrome phone smoke command: `node docs/cataclysm-1-2/qa/chrome-smoke.cjs`. Requires installed Playwright and Chromium (`CHROME_PATH` can override). Tests 390×844 and 844×390, touch movement, nonblank pixels, runtime/asset errors, revive, frozen cards, reroll and fifth-card reachability; writes screenshots/results under `qa/chrome-evidence/`. `RECORD=1` also records an approximately 20-second portrait WebM, requiring Playwright's ffmpeg.

## Tradeoffs / known jank / missing evidence

- **Chrome smoke and gameplay video could not run here.** Installed Chromium aborts before creating a page because its crashpad socket receives `Operation not permitted`; even local server sockets are denied. No screenshots, video, real-phone FPS or visual approval are claimed. The browser smoke program is supplied, but acceptance still needs Chrome portrait/landscape and creator playtesting.
- Returns happen at the death position, preserving the world; the finite grace lets you escape instead of teleporting/erasing enemies. A stationary cat can die again afterward. This is intentional. Perks can add short protection windows, but revival itself cannot chain indefinitely.
- New cards reuse the existing illustrated card motifs. The gun overlay reuses the original drawn brass pistol; its tail may cross the cat's face at some aim angles. Existing cutout pose cycling, busy HUD/banter and phone fifth-card scrolling remain rough pending visual review.
- Rare recovery is an automatic one-time timed lottery, not a bespoke pickup or boss reward. No persistent run save was added; progress preservation is within the current run across revival, as scoped. Existing best-score/audio preferences remain.
- Balance is a first playable pass, not a full 100-night endurance certification. No hardware performance claims. Historical copied evidence files describe previous versions; this report and the new runtime results are the 1.2 evidence.
