## Creative direction: the city has been waiting for this particular cat

A rain-dark service city that its inhabitants kept repairing after everyone else left. Painted brick, softened zinc roofs, fish-market awnings, oxidized canal gates and porcelain station signs contrast with the hero's clean warm whites. Guardians are recognizable **feline city custodians**, corrupted by staying on duty too long. Menace comes from oversized equipment, interrupted routines and readable attack commitments; avoid gore and identical recolored enemies.

Use original small-scale painted illustration: confident dark plum contours, soft gouache-like material shading, visible brush variation at large size, broad readable silhouettes at phone size. Existing hero sheet is the anatomy/rendering reference; its expressive drawn contour can coexist with more textured city surfaces. No photoreal camera, pixel art, voxel, flat infographic buildings, faux 3D toy boxes, stock icons as bosses or gradients pretending to be painted masonry. Original compositions only; no named artist imitation or external IP references.

Projection is fixed overhead streets with shallow three-quarter front faces on props; screen up is world north, no isometric diamond grid. Use 30-degree visible front faces on tall props while their footprints stay axis-aligned. Characters retain side/three-quarter readable faces. Light comes from upper left, shadows lower right. Ground stays low contrast; salmon/amber attack telegraphs, cyan magnet, vermilion rage, ivory beacon each have a distinct icon/shape. Do not bake text, arrows, meters, collision outlines, muzzle flashes or opaque drop shadows into character cutouts.

Palette: wet ink `#15232D`, brick plum `#493442`, canal jade `#315B58`, furnace umber `#674436`, station violet `#524B70`, warm ivory `#F2E8D4`, copper `#DA9569`, signal cyan `#79D8D2`, coral `#ED7884`. Ground value target 15–35%; hero/eyes 70–95%; large hostile silhouettes mid-value with bright equipment accents. Readability wins over microdetail.

## Determinism and navigation contract

Design contract only; no new production JS this pass. Suggested small `city.js` pure module owns topology, routes, gate transitions and guardian reward records. `game.js` continues to own combat, input, life and fish actors.

Derive each feature stream with FNV-1a over UTF-8 `city-v1|<decimal seed>|<district ID>|<purpose>`: start 2166136261, for each byte `h = imul(h XOR byte,16777619) >>> 0`. Feed existing LCG (1664525,1013904223) from this state. Layout/gate eligibility/presentation/combat/card RNG streams must be independent; no frame-rate or viewport input enters topology. Canonical sort IDs before selection. Regenerating an evicted chunk produces identical solids. Persist discovery separately by `{layoutVersion, seed}` under a 1.4-only localStorage key; blocked storage falls back to memory. Discovery is map memory, never a checkpoint or saved combat run.

Build a 40-unit navigation grid (134×134 over city). Rasterize authored solids inflated by actor radius + 8 units; cardinal neighbors only, cost 40 units; remove locked gate edges. Hero and pickup reachability use hero radius, Mecha pathing uses its actual collision radius. Mandatory lanes must also pass `max(heroRadius,mechaRadius)+8` clearance; if it cannot fit, reject layout and choose deterministic clear template, not narrower collision for attractive art. Required dry bridge width 240 and route width 200 minimum are starting values subject to this proof. Player motion uses existing swept/substepped collision and sliding, not cell snapping. Route smoothing is line-of-sight only against the same inflated solids.

At 5Hz or immediately on gate/solid/pickup change, attach player and eligible targets to visible clear grid nodes using collision-tested segments. If no clear attachment exists, exclude target; never snap through a wall. One Dijkstra from player supplies all reachable distances: `d(target)=attachmentStart + gridPathLength + attachmentEnd`. Choose minimum distance across **magnet, rage and actionable beacon only**, tie by stable target ID. Expiring pickups qualify only if `d / max(currentSpeed,1) < timeToLive - 1s`. Consumed/expired/locked/defeated beacon targets are invalid. Ordinary fish, heal, relay, enemies, bosses, guardian portraits and arbitrary quest goals are excluded. Gate beacon on the player's side qualifies; its inaccessible far-side partner does not. No category bias; nearest means nearest by route distance. Do not add hysteresis that secretly chooses a farther target. Cache graph by gate/geometry revision; recalculate player attachment between searches. Avoid a search per enemy or per rendering frame.

Arrow points at first line-of-sight waypoint on the chosen shortest route, **not through a wall toward target center**. Label shows category and rounded-up route meters (`ceil(d/40) m`); 40 world units = 1 displayed meter is UI convention, not physics. Camera maps world to logical canvas before screen-space placement. Define safe rectangle as visible canvas minus actual HUD/touch/bubble exclusion bounds plus 16px padding.
