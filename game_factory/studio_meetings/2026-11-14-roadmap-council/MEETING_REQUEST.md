# CREATOR COMMISSION — Cataclysm one-game continuity / 2.0 roadmap council
**Meeting request:** 14 November 2026. **Current playable milestone:** Cataclysm 1.2 — NINE LIVES. **NO game implementation is authorized in this meeting.**

## The essential correction from the creator
There is **ONE** game called **CATACLYSM**. Versions 0.1–0.9 are its early evolution. **1.0: THE CATASTROPHE** is a major release of that same game. 1.1 and 1.2 improved THAT GAME. The next releases continue that SAME working game, retaining and evolving its playable systems, art, sound, story, enemies, abilities and companions. **2.0: THE CATACOMBS** is the second major release and destination.

There are **eight intermediate updates** after 1.2, in this exact custom sequence, followed by 2.0:
**1.3 → 1.4 → 1.5 → 1.6 → 1.69 → 1.7 → 1.8 → 1.9 → 2.0.**
The creator explicitly requests 1.69 as an interim release, and 1.7 remains in the sequence. **Do not numerically sort these version strings or confuse isolated archival URLs with separate products.**

Each step is a **cumulative improvement opportunity**, not a disposable demo or a rigid silo of only one feature. Each must propose concrete deliverables in the same seven lenses:
1. Mechanics & core combat/player autonomy: how does the actual game change?
2. Content & characters: companions, enemies, areas, bosses, rewards, dialogue and encounters.
3. Graphics & animation: actual textured original art and visible integrated motion.
4. Audio: original soundtrack, responsive music and sound effects, with quiet mix controls.
5. UX/controls: mobile Android/Samsung one-thumb movement-only combat, readable HUD/menu, player-facing teaching.
6. Engineering/QA: integration, deterministic contracts, mobile performance, test evidence and historical release protection.
7. Continuity/dependencies: what is inherited, what belongs in the NEXT release, what must not silently disappear?
