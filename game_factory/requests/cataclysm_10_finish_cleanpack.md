## Confirmed technical evidence — address root causes

1. `docs/cataclysm-1-0-major/animation.js` **loads three overlapping art lineages** for the hero: old 24-frame `hero-*.png` atlases, newer `art/characters/hero/<state>.png` reference overrides, and the directed `art/characters/hero/directed-{run,idle,attack}.png` pack. `ART.draw` picks between them based on state/load timing; damage even paints a second full character silhouette with brightness/filter in the same frame. There is an old procedural entire-cat fallback after those branches. Stop loading unused legacy hero atlases, remove conflicting runtime fallback and redundant whole-body overdraw once one complete clean hero pack is ready; keep older source on disk only if needed by other characters/assets, never select it for the modern hero.
2. The old `game_factory/cataclysm_next/qa/reanimate_hero.py` pre-generated 8-direction sheets with a **soft 12-pixel alpha blend between an eight-way STATIC upper aim pose and a DIFFERENT full-body run pose** (`Image.composite(moving, facing, mask)`, y=58–70). That baked semi-transparent ghost limbs/waist into the *pixels themselves*, so a single canvas draw can still look like two animations. **Retire those generated `directed-*.png` frames as active hero art. Do not repeat crossfade compositing, seam masking, or old/new mixed-body stitch.** A completely new coherent full-body frame, grounded in one approved visual identity, is needed for each actual pose. Real art or a properly articulated rig can be used; don't claim that recoloring an old still is an animation.
3. `game.js` active `catSprite()` immediately returns through `ART.draw()`, yet still contains hundreds of lines of unreachable procedural old-cat drawing after that return. Remove obsolete dead drawing code safely without changing the return contract. Inspect other draw paths for duplicate full bodies: enemies currently get `drawAnatomy(e)` before their cat atlas; this can legitimately add wings/hooks/trait telegraphs but must not draw a second complete body. The hero should render exactly ONE full-body sprite/rig each update. Glows, drop shadows and muzzle flashes may remain non-character effects, outside the one-body contract.
4. The on-device reference clip is approximately ten seconds at 1080×2340. In the 6–9 second area the white hero's torso and legs move far less than the engineer's recognizable kneel; a faint ghost-like behind-layer is perceptible. **Measure in rendered actual mobile pixels** at 390×844; frame-file counts alone do not constitute success.
