# Cataclysm 1.0 — one autonomous studio assignment: make the living cats more alive

**Creator's order, 13 November 2026.** Ship a creative polish of the **currently published** Cataclysm 1.0. Treat the screenshots and previous conversation as critique, not a script to implement word for word. The studio has freedom to invent and reject specific lines, mechanics-free animation details, poses, turret designs, and humor. **Deliver working in-game results, not a pile of assets or a proposal.**

## What must feel different when playing

**The hero is alive throughout every state.** In the latest game the main cat talks and normally moves/aims in eight directions, but an activated buff can replace movement with an almost static full-body pose. Repair the *root animation state selection*: while feral/adrenaline/survival buffs are active, keep recognizable, continuous body and leg movement, directional gun aiming and responsiveness. Give the cat appropriate secondary motions and tasteful variations (tail, ears, anticipation, breath, recoil, stance, expressive idle or recovery) according to the studio's judgment. The approved modern painted hero and directional run/idle/attack atlas family is the visual identity. Extend it with new, coherent animated variant textures or an art-directed motion system—whichever looks demonstrably better on a real mobile screen. **No static buff badge masquerading as character animation; no old/new sprite mixing; no waist-leg cut-and-paste glitches.** Preserve eight-direction facing while moving, firing and buffed. The studio decides frame counts, colors, form, and whether a pose needs more art.

**The engineer's turret deserves genuine art direction.** The current deployed turret is mechanically fine but looks like a rough prototype. Give it a coherent **skin family**, with stylistic variation reflecting combat states, rarity/progression or cooldown as appropriate. It should read as a purposeful little machine at mobile scale: recognizable silhouette, barrel or targeting behavior, firing/impact response, and an interesting end-of-life cue. The studio may invent different skins and occasional tiny visual jokes. Do not invent a paid turret purchase mechanic, manual controls, or change hitbox, DPS, lifetime, target choice, summon count, or performance limits. Use existing asset workflows or create original textures efficiently; no requirement to call a live image model and no network during play.

**Make the hero a better character.** Expand the *local* dialogue library substantially with genuine original lines and branching situations, not copies of the user examples or the previous assistant's suggested text. Invite the writing/design team to establish personality, running jokes, banter with distinct companion personalities, callbacks to events and silly cat-specific misunderstandings. React appropriately to combat pressure, near death, healing, victories, missing shots, fish, companions, changing weather/streets, levels, and approaching final nights. Some lines should be genuinely funny; some terse and serious. Use an event-linked bank with cooldowns, recent-line suppression, context and speaker priorities. Respect existing readable semi-transparent dark bubbles with white, quickly typed text. Do not become a nonstop subtitle machine, interrupt important UI or advertise events that never happened. Preserve reduced-motion behavior and gameplay pause freezing.

## Non-negotiables / integration

- Keep both `docs/cataclysm-1-0-major/**` and `docs/cataclysm-100-lab/**` aligned. Keep Cataclysm **1.0** and public play starting **Night 1, Level 1**. Do not rebuild the project from scratch or regenerate previously accepted art.
- The studio may add genuinely needed new hero/turret texture atlases, animation definitions, dialogue banks, and associated renderer code **inside those two game directories only**. Preserve and reuse all existing approved artwork and working systems; append instead of overwriting protected reference character PNGs.
- Preserve progression including the 6/8/10 early XP thresholds, ranged/silence balance, continuous spawns, fixed infinite city, scoring, existing cards, four-companion cap, fish behavior, dialogue UI, pause Guide, volume, touchscreen/keyboard/fullscreen controls and audio. No new inputs.
- No fixed list of mandated hero quotes. No requirement for a particular count of turret designs or an arbitrary number of animation frames. The creative team chooses scope and style based on quality, technical feasibility, and mobile performance.
- QA must show **actual on-screen temporal motion** of the hero during both normal and buffed walking/firing, facing changes in at least four directions without freezing, visually distinct turret activity and skin treatment on mobile, fresh contextual hero speech across varied events, and zero browser/runtime errors. Screenshots/video or frame/pixel evidence should accompany code. Preserve existing 1.0 functionality in 390×844 portrait and 844×390 landscape, including Samsung-like touch comfort. No Night 100 full-horde stress requirement.
- Do not let legacy asset-compatibility code override the latest painted protagonist or companions. If a feature is unexpectedly difficult, solve the genuine root cause and keep the best working art instead of hiding a static animation behind cosmetic particles.

**One high-level creative assignment, not incremental approvals.** The studio should decompose and coordinate writing, visual design, animation, engineering, and QA internally, then deliver an independently playable candidate. The trusted workflow owns QA and publication. Do not alter tests, pipelines, other games or historical releases during the agent stage.
