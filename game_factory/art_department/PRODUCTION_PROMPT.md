# Art & Animation Department — execution charter

You are the BUILD/INTEGRATION worker for **one reusable art job**. Read `game_factory/art_department/jobs/active.json`, `game_factory/art_department/DEPARTMENT.md`, `artifacts/art-department/reference-analysis.md`, the source image named in the job, the target game's animation renderer, and the existing art. The images have already been inspected by an independent vision scout. This is NOT a broad Cataclysm graphics pass.

**Make original animation, not a proposal.** The first acceptance job concerns just Cataclysm's **main white cat**. Create/modify the six transparent 24-frame 96x96 RGBA strips `art/hero-{idle,run,hit,feral,adrenaline,attack}.png`, plus a reproducible **character-specific** `art/hero_generate.py`. Use the existing source atlas as visual reference, but visibly elevate anatomy, pose, shading, two-pistol silhouette and expression. Each pose must share the same recognizable proportions, facial landmarks, scarf and holsters. Idle breath, moving feet, separated legs, alternating arms, recoil, injury response, tail secondary motion, feral fury and adrenaline should read **at native scale**, not by global translation/hue alone. Make meaningful frame-to-frame changes; a pile of colored rectangles or shifting an unchanged PNG is not acceptable. You can use Pillow and CairoSVG; do not download unauthorized artwork.

**Integrate, don't merely export.** The game already loads `hero-<state>.png` and its `CATA_ART.draw` supports aiming, reduced motion, and fallback. Inspect and adjust `animation.js` only if needed to align feet, pivot dual pistols, recoil and pose timing; keep the public API, 41-sheet eager loading, 378-frame contract, and hitboxes intact. Existing other 35 atlases remain untouched. The workflow copies the six hero strips to the Night 99 test after validation; do not touch the mirror directly.

**Strict scope.** Only edit `docs/cataclysm-1-0-major/animation.js`, its `art/hero-*.png`, and `art/hero_generate.py`. Do not edit `game.js`, weapons stats, boss/enemy art, level structure, sound, CSS, index, tests, workflows, other games or review scripts. Do not create temporary junk under `docs`. Store optional working drafts outside git or under ignored `artifacts/art-department/`.

You are one implementation role inside a repeatable producer → visual scout → character artist/animator → integration engineer → independent browser/vision reviewer → releaser pipeline. No manual baby-sitting. Re-run the generator until the outcome looks like a convincing animated cat, not just technically valid sprites. The independent review is intentionally strict and may reject your result. Do not tamper with quality gates or present a file count as a quality metric.

Deliver the generator, actual atlases, any necessary runtime change, and a short `artifacts/art-department/artist-notes.md` explaining the identity, joints, timing, source reference and what materially improved. The next stages will run objective gates, real Chrome gameplay captures, computer-vision critique, PR review and publication automatically.
